# Far From Home v1.3.0 - Shadows and Salvage

Playable Windows x64 survival-horror preview, built with Godot 4.7.2.

## Changes since v1.2.0

- Weathered coffin stacks in the Saint George cellar, with a mummy bursting out of an upright coffin and a deep scream. After the second tunnel monster dies, the flashlight fails until the coffin scare restores it. Normal battery changes and F10 cannot bypass this moment.
- A silent figure watches from a lit upstairs hotel window. On approach, the figure disappears and the light flickers out. A few main-menu windows have subtle independent light fluctuations.
- A Main Menu button in the pause screen returns to the title screen and resets the current journey.
- New road assets and continuous asphalt from the crash to the chapel approach. The spawn road matches Main Street's width. Background hills are cut away from the playable road and house to eliminate the pale geometry strip.
- The wreck's rear hatch opens and closes immediately with E or controller interaction. Collect the backpack and flashlight from the trunk; the detour sheet is optional. Pickup targets match the objects. The original driver-door hinge is restored, trunk items clear the back seat, and both doors remain interactive in F10 mode.
- Source import repairs for the coffin color map and shovel normal texture.

## Play

Download **FarFromHome-v1.3.0-Windows-x64.zip**, extract it completely, and run **FarFromHome.exe**. Keep the EXE and PCK together. Godot is not required. Read README.md for controls and testing mode. Source, asset credit records, build information and SHA256 checksums accompany this release.

The in-game Check for Updates feature supports this preview. Existing achievements persist; new journeys reset gameplay progress. Windows x64 uses ANGLE/Direct3D11 compatibility rendering with PS2-style presentation. This remains a development preview.
